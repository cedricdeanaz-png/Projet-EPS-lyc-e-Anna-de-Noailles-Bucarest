# EPS · Lycée Français Anna de Noailles – Bucarest

Application du département EPS du Lycée Français Anna de Noailles : programmes, programmation et grilles d'évaluation, protocole du baccalauréat, inaptitudes, association sportive et contacts de l'équipe.

L'application est publiée avec GitHub Pages et peut être ajoutée à l'écran d'accueil d'un téléphone comme une application.

## Fichiers

- `index.html` : l'application complète
- `manifest.json` : nom, couleurs et icônes de l'application installable
- `icon-192.png`, `icon-512.png` : icônes Android
- `apple-touch-icon.png` : icône iPhone et iPad
